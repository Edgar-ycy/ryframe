# 数据库读一致性分类

本文定义 `ControlDatabaseCluster` 的控制面读取边界。系统查询必须显式调用
`select_read(ReadConsistency)`；命令、事务、锁和 CAS 继续使用 `write()`。

## 选择规则

| 类型 | 选择 | 说明 |
| --- | --- | --- |
| 认证、授权、权限、数据范围、安全与配额判断 | `Strong` | 只能从主库作出安全决策 |
| 唯一性检查、命令前置读取、写后读 | `Strong` 或同一主库事务 | 不允许副本延迟改变命令结果 |
| 消息收件箱、未读数、确认状态 | `Strong` | 客户端重连和确认依赖最新状态 |
| 文件及导出结果下载定位 | `Strong` | 避免刚写入的元数据因副本延迟返回 404 |
| 普通列表、详情、日志和业务数据导出 | `Eventual` | 可以读取健康副本，副本不可用时由路由器选择主库 |
| Worker 领取、租约、重试、状态迁移、清理 | 主库 | 这些读取是锁、CAS 或状态机的一部分 |
| 代码生成器元数据 | 指定数据源 | 使用 `generator.data_source`，不参与业务副本路由 |

`select_read` 只在执行 SQL 前选择连接。查询一旦发送后，框架不得把失败 SQL
自动重放到主库；这样可以避免无法证明幂等的语句被执行两次。副本故障由后台监督器
摘除，后续新的最终一致性查询才会选择其他健康节点或主库。

## 查询入口清单

| 入口 | 当前分类 |
| --- | --- |
| `AuthService` 登录、刷新、当前身份、WebSocket 会话校验 | `Strong` / 主库 |
| 授权快照、用户授权版本、租户授权纪元 | `Strong` / 主库与 Redis 原子脚本 |
| `UserService` 分页、详情、导出、候选项、权限与可访问性检查 | `Strong`，因为查询携带数据范围或参与授权判断 |
| `DeptService` 树、分页、详情 | `Strong`，因为部门层级参与数据范围判断 |
| `PermissionService` 权限树、详情、角色权限 | `Strong` |
| `RoleService::find_options`、角色权限代码 | `Strong`；角色分页、详情、导出为 `Eventual` |
| 菜单树、按权限过滤的菜单树、菜单分页与详情 | `Eventual`；传入的权限集合必须来自强一致授权快照 |
| 个人资料读取 | `Strong` |
| 参数分页、详情和导出 | `Eventual`；普通键查询热命中零 SQL，缓存未命中固定回源 `Strong`；认证前公开参数读取为 `Strong` 并绕过缓存 |
| 字典类型、字典数据、岗位、通知、租户普通查询 | `Eventual` |
| 登录日志、操作日志分页与导出 | `Eventual` |
| 消息收件箱、未确认消息、未读数及分发状态读取 | 主库 |
| 导出任务列表 | `Eventual`；任务详情、取消前置读取和下载定位为 `Strong` |
| 文件下载元数据 | `Strong`；上传预留、补偿和清理状态机使用主库 |
| 后台任务列表、统计、监控、领取、重试及 Outbox | 主库，保证运维视图与状态机使用同一状态源 |
| 在线用户、验证码、WebSocket 票据 | Redis 或进程内状态，不执行 SQL |
| API 与独立 Worker `readyz` | 只读后台探测生成的内存快照，请求路径不执行 SQL、Redis 或对象存储网络调用 |

API Handler 不直接持有数据库连接，只调用 Service。独立 Worker 当前只构建主库
`ControlDatabaseCluster`，因此 Worker 内部的 `Eventual` 控制面导出查询也会选择主库；若以后让
Worker 使用副本，必须同时接入副本结构校验、健康监督和关闭流程，不能只复制连接配置。

## 评审要求

- 新增查询时，代码评审必须说明选择 `Strong` 或 `Eventual` 的原因。
- 不得用 `write()` 代替普通查询以绕过分类；仅命令前置读取、事务、锁、CAS 和 Worker
  状态机可以直接使用主库。
- 缓存命中路径不得提前调用 `select_read`，否则会产生并不存在的数据库选择与回退指标。
- 需要跨多条 SQL 保持同一快照时，应使用只读事务或重新设计仓储接口，不能依赖连接池
  恰好返回同一物理连接。
